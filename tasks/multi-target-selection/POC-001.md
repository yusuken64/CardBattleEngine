Requirements:
1. Read the durability gotcha before writing this file: `Minion.RecalculateStats()` (`CardBattleEngine\Entities\Minion.cs`) rebuilds `MaxHealth` from `OriginalCard.Health` plus modifiers on every call, and the engine calls `RecalculateStats()` on every entity after every action resolution (when not running a simulation). This means directly assigning `MaxHealth` would be silently discarded almost immediately. Only `.Health` (current health) is safe to mutate directly — this is exactly what `DamageAction`/`HealAction` already do. **This effect swaps only current `Health`, clamped to each target's own (unchanged) `MaxHealth`** — it does not durably swap the max-health stat. If a future card needs to swap max health durably, that would go through `AddStatModifierAction` with a `Set` modifier type instead — explicitly out of scope here.
2. Create the new file:
```csharp
namespace CardBattleEngine;

public class SwapHealthAction : GameActionBase
{
    public override EffectTrigger EffectTrigger => EffectTrigger.None;

    public override bool IsValid(GameState state, ActionContext context, out string reason)
    {
        reason = null;
        return context.Targets != null &&
               context.Targets.Count == 2 &&
               context.Targets[0].IsAlive &&
               context.Targets[1].IsAlive;
    }

    public override IEnumerable<(IGameAction, ActionContext)> Resolve(GameState state, ActionContext context)
    {
        if (!IsValid(state, context, out _))
            yield break;

        var a = context.Targets[0];
        var b = context.Targets[1];

        int aHealth = a.Health;
        int bHealth = b.Health;

        a.Health = Math.Clamp(bHealth, 0, a.MaxHealth);
        b.Health = Math.Clamp(aHealth, 0, b.MaxHealth);

        if (a.Health <= 0)
            yield return (new DeathAction(), new ActionContext { SourcePlayer = context.SourcePlayer, Source = a, Targets = [a] });
        if (b.Health <= 0)
            yield return (new DeathAction(), new ActionContext { SourcePlayer = context.SourcePlayer, Source = b, Targets = [b] });
    }
}
```
Verify `Math.Clamp(int, int, int)` is available (it's a standard .NET method — confirm the project's target framework supports it; if the codebase has its own `Utils.Clamp` helper used elsewhere for the same purpose, e.g. in `DamageAction.cs`/`HealAction.cs`, use that helper instead for consistency). Verify `IGameEntity.Health` and `IGameEntity.MaxHealth` (or wherever `MaxHealth` actually lives — check `Minion.cs`; `Player`/hero entities may not have a `MaxHealth` concept, but this effect is intended for minion-vs-minion use given its `ValidTargetSelector` will restrict to minions in the test card) are settable/gettable as shown.
