Task ID:
NTR-012

Model:
haiku

Title:
Add TriggeredEffect.TargetRequirement, propagate through Clone()

Purpose:
Today `TriggeredEffect.AffectedEntitySelector` is the only way a triggered ability (e.g. "whenever this minion attacks, deal 3 damage") supplies targets, and it's fully programmatic (no player interaction possible). This adds an alternative: a triggered effect can declare `TargetRequirement` instead, meaning its effect needs the player to interactively pick targets before it resolves — e.g. "whenever this minion attacks, select a minion, that minion takes 3 damage."

Dependencies:
NTR-001

Consumes:
NTR-001: `TargetRequirement`.

Produces:
`TriggeredEffect.TargetRequirement`, consumed by NTR-013 (`TriggerEffectAction` branches on whether `AffectedEntitySelector` or `TargetRequirement` is set).

Files:
CardBattleEngine\Entities\TriggeredEffect.cs

Requirements:
1. In the `TriggeredEffect` class, add a new property alongside the existing `AffectedEntitySelector`:
```csharp
public TargetRequirement TargetRequirement { get; set; }
```
2. In `TriggeredEffect.Clone()`, add:
```csharp
TargetRequirement = TargetRequirement,
```
alongside the existing `AffectedEntitySelector = AffectedEntitySelector,` line (reference copy, matching how `AffectedEntitySelector` is already cloned).

Constraints:
- Do not touch `ExpirationTrigger`, `ITriggeredEffect`, or any enum in this file.
- Do not add any validation enforcing "exactly one of `AffectedEntitySelector`/`TargetRequirement` may be set" — that's a concern for whoever authors a `TriggeredEffect`, not for this data class. `TriggerEffectAction` (task NTR-013) decides which one to honor at resolution time.
- Default value for `TargetRequirement` is `null` — every existing `TriggeredEffect` (which never sets it) is completely unaffected.

Acceptance Criteria:
- `TriggeredEffect.TargetRequirement` exists, defaults to `null`.
- `TriggeredEffect.Clone()` copies `TargetRequirement` onto the cloned instance.
- No existing content or test that only sets `AffectedEntitySelector` changes behavior.

Validation:
Run `dotnet build CardBattleEngine.sln` — should succeed (purely additive).

Handoff:
Task NTR-013 depends on this property existing.
