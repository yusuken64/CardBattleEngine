Title:
Add Card.RequiredTargetCount and Card.AllowDuplicateTargets, propagate both through Clone()

Purpose:
Lets a card declare it needs more than one player-selected target (e.g. "pick 2 minions, swap their health") and whether the same entity may be picked more than once. Defaulting both to their "single distinct target" values guarantees zero behavior change for every existing card.

Dependencies:
PHASEA-EXIT

Consumes:
PHASEA-EXIT: a stable, fully green, `ActionContext.Targets`-based codebase to build on.

Produces:
`Card.RequiredTargetCount` and `Card.AllowDuplicateTargets`, consumed by: NTR-007 (`GameState.GetValidActions` reads both to build a `TargetRequirement`), NTR-008 (`PlayCardAction.IsValid` validates the picked count against `RequiredTargetCount`), NTR-009 (`ValidTargetRestriction.CanPlay` checks enough candidates exist), POC-001/POC-002 (the `SwapHealthAction` proof-of-concept test card sets `RequiredTargetCount = 2`).

Files:
CardBattleEngine\Entities\Card.cs
CardBattleEngine\Entities\MinionCard.cs
CardBattleEngine\Entities\SpellCard.cs
CardBattleEngine\Entities\WeaponCard.cs

Requirements:
1. In `CardBattleEngine\Entities\Card.cs`, add to the abstract base class, near `ValidTargetSelector`:
```csharp
public int RequiredTargetCount { get; set; } = 1;
public bool AllowDuplicateTargets { get; set; } = false;
```
2. In each of `MinionCard.cs`, `SpellCard.cs`, and `WeaponCard.cs`, find the `Clone()` method (each already copies other properties like `CastRestriction` and `ValidTargetSelector` — find that exact pattern) and add two lines propagating both new properties alongside those, matching whatever assignment style (object-initializer, direct field assignment) the surrounding lines already use in that specific file.

Constraints:
- Default values must be exactly `RequiredTargetCount = 1` and `AllowDuplicateTargets = false` — this preserves existing single-target, no-duplicates behavior for every current card with zero other changes.
- Do not add any validation, setter logic, or range-checking to either property — plain auto-properties.
- Do not touch any other property or method in `Card.cs`, `MinionCard.cs`, `SpellCard.cs`, or `WeaponCard.cs` beyond the two property additions and the three two-line `Clone()` additions.

Acceptance Criteria:
- `Card.RequiredTargetCount` (`int`, default `1`) and `Card.AllowDuplicateTargets` (`bool`, default `false`) both exist.
- `MinionCard.Clone()`, `SpellCard.Clone()`, and `WeaponCard.Clone()` each copy both new properties onto the cloned instance.
- No existing test changes behavior, since every existing card keeps both default values.

Validation:
Run `dotnet build CardBattleEngine.sln` — should succeed cleanly (purely additive).
