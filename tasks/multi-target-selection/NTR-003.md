Title:
New file: Choice\TargetSelectionChoice.cs — generic pending choice for picking targets for ANY paused action

Purpose:
This is the generic replacement for the earlier card-specific `MultiTargetChoice` design. It holds a reference to whatever action/context is paused waiting for targets (a card play, a triggered ability's damage effect, anything), not just "a card." Once enough targets are picked, the original action gets re-run with them — the choice itself doesn't know or care what that action is.

Requirements:
Create a new file implementing `IPendingChoice` (check `Choice\SimpleChoice.cs` and `Choice\DiscoverChoice.cs` for the exact interface shape/namespace conventions to match):
```csharp
namespace CardBattleEngine;

public class TargetSelectionChoice : IPendingChoice
{
    public Player SourcePlayer { get; set; }
    public IGameAction PendingAction { get; set; }
    public ActionContext PendingContext { get; set; }
    public TargetRequirement Requirement { get; set; }
    public List<IGameEntity> PickedSoFar { get; set; } = new();
    public IEnumerable<(IGameAction, ActionContext)> Options { get; set; }

    public IEnumerable<(IGameAction, ActionContext)> GetActions(GameState gameState)
    {
        if (Options != null) return Options;

        var candidates = Requirement.Provider.Select(gameState, SourcePlayer, PendingContext.SourceCard);
        candidates = UntargetableFilter.ExcludeUntargetable(candidates, SourcePlayer);

        if (!Requirement.AllowDuplicateTargets)
            candidates = candidates.Where(e => !PickedSoFar.Contains(e));

        Options = candidates.Select(entity => (
            (IGameAction)new SupplyTargetAction { Choice = this, Candidate = entity },
            new ActionContext { SourcePlayer = SourcePlayer, SourceCard = PendingContext.SourceCard }
        )).ToList();

        return Options;
    }
}
```
Adjust namespace/using directives to exactly match the conventions already used by `Choice\SimpleChoice.cs` and `Choice\DiscoverChoice.cs`. `SupplyTargetAction` is defined by a separate task (NTR-004, new file `Actions\SupplyTargetAction.cs`) — this file will not compile stand-alone until that type exists; that is expected and acceptable for this task in isolation.

- Do not modify `GameEngine.cs`, `SimpleChoice.cs`, `IValidTargetSelector.cs`, or `UntargetableFilter.cs` in this task.
- This class must be agnostic of what `PendingAction` actually is — do not special-case `PlayCardAction`, `DamageAction`, or any other concrete action type here. That's the whole point of the redesign: this choice type works identically regardless of what kind of action is waiting on targets.
