Title:
Migrate ActionContext.Target (singular) to ActionContext.Targets (ordered list)

Purpose:
Every other task in this plan depends on this one field-shape change landing first. This is the foundational contract change that lets a future effect ("pick 2 minions, swap their health") see multiple player-selected targets at once instead of exactly one.

Dependencies:
(none — this is the first task)

Produces:
New shape of `ActionContext`: `public List<IGameEntity> Targets;` replacing `public IGameEntity Target;`, and an updated `ResolveTargets` fallback chain. Every other task in this plan (all MECH-*, SPEC-*, FWD-*, and all Phase B/C tasks) consumes this shape.

Files:
CardBattleEngine\Interfaces\GameActionBase.cs

Requirements:
1. In the `ActionContext` class, replace the field `public IGameEntity Target;` with `public List<IGameEntity> Targets;`.
2. In the `ActionContext` copy constructor, replace `this.Target = context.Target;` with `this.Targets = context.Targets;` (this is a reference copy, same treatment as `Source`/`SourcePlayer` — do NOT deep-copy the list here).
3. Update the `ResolveTargets(GameState state, ActionContext context)` method (currently returns based on a fallback chain: `AffectedEntitySelector` → single `Target` → `SourcePlayer` fallback → empty) to:
```csharp
protected IReadOnlyList<IGameEntity> ResolveTargets(GameState state, ActionContext context)
{
    IEnumerable<IGameEntity> targets;

    if (context.AffectedEntitySelector != null)
        targets = context.AffectedEntitySelector.Select(state, context);
    else if (context.Targets != null && context.Targets.Count > 0)
        targets = context.Targets;
    else if (context.SourcePlayer != null)
        targets = [context.SourcePlayer];
    else
        targets = Enumerable.Empty<IGameEntity>();

    return targets.Where(t => t != null && t.IsAlive && t.Health > 0).ToList();
}
```
Preserve whatever the existing method's exact filtering predicate is (the `Where` clause above is illustrative of intent — check the current method body and keep its existing alive/health filtering logic verbatim, only change the middle branch from reading `context.Target` to reading `context.Targets`).
4. Do not touch any other file. Every other call site that reads or writes `.Target` elsewhere in the solution will now fail to compile — that is expected and is fixed by separate, already-planned follow-up tasks. Do not attempt to fix other files.
